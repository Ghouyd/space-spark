# Space Spark

Space Spark is an interactive educational web game designed to make learning enjoyable and engaging for children through a space-themed experience.

The game contains three educational planets: Numbers Planet, Letters Planet, and Animals Planet.

## Main Features

* Interactive educational activities
* Stars reward system
* Audio pronunciation
* User login and profile
* Multiple learning levels
* Progress tracking through a database
* Child-friendly space-themed interface

## Learning Planets

### Numbers Planet

The Numbers Planet contains five progressive learning levels:

1. Basic Numbers
2. Addition
3. Subtraction
4. Multiplication
5. Division

### Letters Planet

The Letters Planet helps children learn the alphabet through four levels:

1. Letters
2. Listening
3. Reading
4. Word Building

### Animals Planet

The Animals Planet introduces children to animals through four levels:

1. Animals
2. Animal Sounds
3. Animal Food
4. Animal Habitats
